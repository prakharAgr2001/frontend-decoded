## Key points
- **Colocation**: keep state **as close as possible to where it's used**, and no higher.
- When two components need the same state, lift it only to their **closest common parent**.
- State placed too high makes **every update re-render a large part of the tree**.

## Interview answer
> I colocate state with the components that use it. If siblings need to share it, I lift it to their nearest common parent rather than to the top of the app. State that's too high causes unnecessary re-renders of everything below it and makes components harder to move or delete. Only genuinely app-wide values like the current user, theme or locale go global, and even those are split by concern rather than kept in one big object.

## The analogy
Keeping your toothbrush in the bathroom, not in a central storeroom in the basement. You only move it somewhere shared if two people actually need it, and even then, to the nearest shared bathroom.

## How it works
```compare
State too high || Colocated
search text in <App> || search text in <SearchBox>
Typing re-renders the whole page || Typing re-renders only the search box
Deleting a feature leaves unused state behind || Deleting the component deletes its state
```

```jsx
// Two siblings need it → lift to the nearest common parent, not to App
function ProductPage() {
  const [size, setSize] = useState('M');
  return (<>
    <SizePicker value={size} onChange={setSize} />
    <AddToCart size={size} />
  </>);
}
```

```jsx
// Heavy parts as children don't re-render when the wrapper's state changes
function Collapsible({ children }) {
  const [open, setOpen] = useState(true);
  return (<section><button onClick={() => setOpen(o => !o)}>Toggle</button>{open && children}</section>);
}
<Collapsible><ExpensiveChart /></Collapsible>
```

## Common traps
- **"Put it in global state just in case."** You pay for it in re-renders and complexity.
- **Lifting too far** instead of to the closest common parent.
- **One giant global object.** Split by concern (user, theme, cart).

## See it yourself
React DevTools → enable **Highlight updates** → type in a search box. If the whole page flashes, the state is too high.
