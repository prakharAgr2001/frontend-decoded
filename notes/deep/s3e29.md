## Key points
- **`startTransition`** marks a state update as **non-urgent**. React renders it in the background and can **interrupt** it if the user types again. `isPending` lets you show subtle feedback.
- **`useDeferredValue`** does the same when you don't control the state setter (e.g. a prop).
- The **React Compiler** (v1.0, late 2025) adds memoization **automatically at build time**.

## Interview answer
> useTransition lets me split updates into urgent ones, like updating the input value, and non-urgent ones, like filtering a large list. Updates inside startTransition render at lower priority and are interruptible, so typing stays responsive, and isPending indicates background work. useDeferredValue gives a lagging copy of a value for the same purpose. The React Compiler analyses components at build time and inserts memoization automatically, reducing the need for manual useMemo and useCallback. Neither makes the work itself smaller.

## The analogy
A waiter who takes your drink order immediately (urgent) but tells the kitchen the dessert order can wait. If you change your dessert, the kitchen just drops the old one and starts the new one.

## How it works
```jsx
function Search({ allItems }) {
  const [query, setQuery] = useState('');
  const [results, setResults] = useState(allItems);
  const [isPending, startTransition] = useTransition();

  function onChange(e) {
    setQuery(e.target.value);                         // urgent: input updates instantly
    startTransition(() => {
      setResults(allItems.filter(i => i.name.includes(e.target.value)));   // can be interrupted
    });
  }

  return (<>
    <input value={query} onChange={onChange} />
    <ul style={{ opacity: isPending ? 0.6 : 1 }}>{results.map(r => <li key={r.id}>{r.name}</li>)}</ul>
  </>);
}
```

```jsx
// When the value comes from props, defer it instead
const deferredQuery = useDeferredValue(query);
```

## Common traps
- **Transitions don't make work faster**, only interruptible. Still virtualize big lists and do less.
- **Controlled input inside a transition.** Keep the input's own state update outside `startTransition`.
- **Compiler isn't magic.** It skips components that break the Rules of React.

## See it yourself
Type quickly into a filter over 10,000 items with and without `startTransition` (CPU 4x slowdown). Without it, typing lags; with it, the input stays smooth. With the compiler on, React DevTools shows a **Memo ✨** badge on optimised components.
