## TL;DR
- **Event delegation:** put **one listener on a parent** instead of one on every child. Use `e.target.closest(...)` to find which child was clicked.
- It works for children **added later**, uses fewer listeners, and avoids leaks when items are removed.
- It relies on **bubbling**, so it doesn't work with events that don't bubble, or if a child calls `stopPropagation()`.

## Say it in the interview
> Event delegation means attaching a single listener to a common ancestor and using event bubbling to handle events from its descendants. Inside the handler I use event.target.closest with a selector to find the relevant child and check that it's inside the container. This reduces the number of listeners, automatically handles dynamically added elements, and avoids cleanup issues. It doesn't work for non-bubbling events like focus, where I'd use focusin instead.

## The analogy
A class with 60 students. Instead of giving each student their own phone to call the teacher (60 listeners), there's **one receptionist at the door** who hears everyone and checks the name tag: "Ah, that's Riya from row 3."

## How it works
```compare
❌ One listener per row || ✅ One listener on the list
1,000 rows = 1,000 listeners || 1,000 rows = 1 listener
New rows need new listeners || New rows just work
Removed rows must be cleaned up || Nothing to clean up
```

```js
const list = document.querySelector('#todo-list');

list.addEventListener('click', e => {
  const row = e.target.closest('.todo');      // walk up from what was clicked
  if (!row || !list.contains(row)) return;    // clicked empty space or outside

  if (e.target.closest('.delete')) row.remove();
  else row.classList.toggle('done');
});

// Rows added later work automatically
list.insertAdjacentHTML('beforeend', '<li class="todo">New task <button class="delete">✕</button></li>');
```

- React already does this for you: it attaches one listener per event type at the root and dispatches to your components.

## Traps interviewers love
- ⚠️ **Using `e.target` directly.** If the row contains a `<span>` or icon, `e.target` is that inner element. Always use `closest()`.
- ⚠️ **Non-bubbling events.** `focus`/`blur` won't reach the parent; use `focusin`/`focusout`.
- ⚠️ **A child's `stopPropagation()`** means the parent never hears the click, so the delegated handler silently doesn't run.

## See it yourself
DevTools → **Elements** → select a row → **Event Listeners** → tick **Ancestors**: on a delegated list you'll see one click listener on the parent, none on each row.

## Quick quiz
<details><summary>Why use closest() instead of checking e.target.classList?</summary>

The click may land on a nested element (icon, span). closest() walks up from the clicked element to the nearest matching ancestor, so it finds the row either way.
</details>
<details><summary>Why does delegation work for elements added after page load?</summary>

The listener is on the parent, which already exists. Clicks on new children bubble up to it like any other.
</details>
<details><summary>When does delegation not work?</summary>

For events that don't bubble (focus, blur, mouseenter), or when something below calls stopPropagation.
</details>
