## Key points
- **Skeleton screens** show the page's layout before the data arrives, which makes loading feel faster.
- The skeleton must **match the real layout**, or content jumps when it loads (CLS).
- Don't flash them: show a skeleton only if loading takes longer than about **200 ms**. Use skeletons for content, spinners for actions.

## Interview answer
> Skeletons replace blank screens or full-page spinners with placeholders shaped like the final content, which improves perceived performance and sets expectations. They must have the same dimensions as the real content to avoid layout shift. I show them only on the first load when there's no data, keep showing existing data during background refetches with a subtle indicator, and avoid flashing them for very fast responses by delaying them slightly. For user actions like saving, a spinner or disabled state on the button is more appropriate.

## The analogy
A restaurant that seats you and sets the plates and cutlery while the food cooks. You know exactly what's coming and where, so the wait feels shorter than standing at the door.

## How it works
```compare
Skeleton || Spinner
First load of content (lists, cards, profiles) || Actions: save, submit, pay
Shows the shape of what's coming || Shows that something is happening
Must match the final layout || Lives on the button that was pressed
```

```jsx
function Orders() {
  const { data, isPending, isFetching } = useQuery({ queryKey: ['orders'], queryFn: getOrders });
  if (isPending) return <OrderListSkeleton rows={5} />;          // same row height as real rows
  return <OrderList orders={data} refreshing={isFetching} />;    // keep old data while refetching
}
```

## Common traps
- **Skeleton sizes that don't match** the real content cause layout shift.
- **Flashing skeletons** on fast responses look glitchy; delay them ~200 ms.
- **Replacing existing data with a skeleton on refetch.** Keep the old data and show a small indicator.

A spinner or disabled state on the button. Skeletons are for loading content.
