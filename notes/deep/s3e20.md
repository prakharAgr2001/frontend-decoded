## Key points
- While a web font loads, the browser either hides text (**FOIT**, flash of invisible text) or shows a fallback then swaps (**FOUT**, flash of unstyled text).
- `font-display` controls this: **`block`** (hide briefly), **`swap`** (fallback now, swap later), **`optional`** (use the font only if it's already fast).
- `swap` can cause **layout shift**; fix with a size-matched fallback (`size-adjust`, `ascent-override`).

## Interview answer
> Web fonts can cause invisible text or a visible swap. font-display swap shows a fallback immediately and replaces it, which avoids invisible text but can shift layout if the fonts have different metrics, so I define a fallback font-face with size-adjust and metric overrides to match. To make fonts arrive sooner I self-host woff2 files, subset them, and preload the one or two most important ones. For the best Core Web Vitals, font-display optional avoids both invisible text and late shifts, at the cost of sometimes not showing the brand font on slow first visits.

## The analogy
A guest speaker running late. **block**: the stage stays silent until they arrive. **swap**: a stand-in starts talking, then the real speaker takes over mid-sentence. **optional**: if they're not here in time, the stand-in does the whole talk.

## How it works
```compare
font-display || What users see
block || Invisible text for up to ~3 s, then the font
swap || Fallback text immediately, swaps when loaded (possible shift)
optional || Font only if it loads very quickly, else fallback for this visit
```

```css
@font-face {
  font-family: 'Inter';
  src: url('/fonts/inter-latin.woff2') format('woff2');
  font-display: swap;
}
@font-face {                        /* fallback sized like Inter, so the swap doesn't shift text */
  font-family: 'Inter Fallback';
  src: local('Arial');
  size-adjust: 107%;
  ascent-override: 90%;
}
body { font-family: 'Inter', 'Inter Fallback', sans-serif; }
```

## Common traps
- **Preloading many fonts** competes with the hero image. Preload one or two at most.
- **Google Fonts from another origin** adds connection time; self-hosting avoids it.
- **Shipping all character sets.** Subset to the scripts you need (e.g. Latin, Devanagari).

## See it yourself
DevTools → **Network** → filter **Font** → throttle to Slow 4G and reload: watch the text flash or swap. Rendering tab → **Layout Shift Regions** shows swap shifts.

## Quick quiz
<details><summary>FOIT vs FOUT?</summary>

FOIT: text is invisible until the font loads. FOUT: fallback text shows first, then swaps to the web font.
</details>
<details><summary>How do you prevent layout shift from a font swap?</summary>

Use a fallback font-face with size-adjust and ascent/descent overrides so it takes the same space as the web font.
</details>
<details><summary>Why can font-display: optional be best for Core Web Vitals?</summary>

It never hides text and never swaps late, so no FOIT and no font-related layout shift.
</details>
