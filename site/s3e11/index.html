Key points

  • preconnect: do DNS + TCP + TLS to another origin early. dns-prefetch: DNS only (cheaper).
  • preload: download a resource this page needs, found late, at high priority. Needs as.
  • prefetch: download something for the next page, at lowest priority.

Interview answer

Resource hints let me tell the browser about work before it would discover it. preconnect sets up the connection to a critical third-party origin, like a font or image CDN. dns-prefetch does only the DNS lookup and is a cheaper fallback. preload fetches a resource the current page definitely needs but discovers late, such as the hero image or a font, with the right as attribute. prefetch downloads resources for a likely next navigation at idle priority. Overusing preload hurts because it competes for bandwidth.

The analogy

Planning a trip. preconnect = book the cab in advance. preload = pack the passport first because you definitely need it today. prefetch = keep tomorrow's clothes ready in case you go out.

How it works

<link rel="preconnect" href="https://images.example-cdn.com">
<link rel="preload" href="/fonts/inter.woff2" as="font" type="font/woff2" crossorigin>
<link rel="preload" href="/hero.avif" as="image" fetchpriority="high">
<link rel="prefetch" href="/checkout.js">

Common traps

  • Preloading everything steals bandwidth from what matters; Chrome warns about preloads not used within a few seconds.
  • Font preload without crossorigin downloads the font twice (fonts are fetched in CORS mode).
  • Too many preconnects waste sockets and CPU on connections you may not use.

See it yourself

DevTools → Network → right-click headers → enable Priority. Add a preload and watch the resource move earlier with High priority.

Quick quiz

preload vs prefetch?

preload is for the current page, high priority, things needed soon. prefetch is for a future navigation, lowest priority.

Why must font preloads include crossorigin?

Fonts are requested in CORS mode; without crossorigin the preload doesn't match the real request, so the font downloads twice.

What does preconnect save?

The DNS lookup, TCP handshake and TLS handshake to that origin, done before the first request needs them.

  • preconnect (DNS+TCP+TLS early) · dns-prefetch (DNS only) · preload (this page, late-discovered, high priority, needs as) · prefetch (next page, lowest priority).
  • See it: Network → Priority column. Trap: preloading everything steals bandwidth; Chrome warns about unused preloads; font preload needs crossorigin or it downloads twice.
