Key points

  • Load timeline: TTFB (first byte, good ≤ 0.8 s) → FCP (first content painted, good ≤ 1.8 s) → LCP.
  • Slow TTFB = server time, distance, redirects. Fix with CDNs, caching and fewer redirects.
  • TBT (Total Blocking Time) = for each long task between FCP and interactive, add (duration − 50 ms). It's Lighthouse's lab stand-in for INP and its biggest-weighted metric.

Interview answer

TTFB measures time until the first byte of the HTML arrives, which reflects server processing, network distance and redirects. FCP is when the first text or image is painted. LCP is when the largest element is painted. TBT is a lab metric: for every long task between FCP and Time to Interactive, it sums the time beyond 50 ms. It correlates with responsiveness and carries the largest weight in the Lighthouse performance score, at 30%.

The analogy

Waiting for a train. TTFB: the train appears on the horizon. FCP: the first carriage reaches the platform. LCP: the carriage you're boarding arrives. TBT: how long the doors stayed jammed shut after that.

How it works

TBT puzzle: three tasks of 70 ms, 140 ms and 40 ms → (70−50) + (140−50) + 0 = 110 ms. The 40 ms task isn't long, so it adds nothing.

Common traps

  • Redirect chains. http → https → www → /en adds a full round trip per hop before TTFB.
  • TBT is lab-only. It's a proxy; real responsiveness is INP in the field.
  • Fast TTFB but slow FCP usually means render-blocking CSS or JS.

See it yourself

DevTools → Network → document request → Timing for TTFB ("Waiting for server response"). Lighthouse → Performance → metrics section for FCP, LCP and TBT.

Quick quiz

Calculate TBT for tasks of 120 ms, 50 ms and 80 ms.

70 + 0 + 30 = 100 ms. A 50 ms task isn't over the threshold.

What usually causes a slow TTFB?

Slow server processing or database queries, a server far from the user, no caching, and redirect chains.

Which Lighthouse metric has the highest weight?

Total Blocking Time (30%).

  • TTFB (first byte, good ≤ 0.8 s) → FCP (first anything, ≤ 1.8 s) → LCP. Slow TTFB = server, distance, redirects → CDN, caching.
  • TBT = sum over long tasks of (duration − 50 ms) between FCP and interactive. Lab stand-in for INP; Lighthouse weight 30% (largest).
  • Puzzle: tasks 70, 140, 40 ms → TBT = 20 + 90 + 0 = 110 ms.
