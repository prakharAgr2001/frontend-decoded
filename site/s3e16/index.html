Minify + Brotli

Key points

  • Minify: remove whitespace and comments, shorten local variable names. Compress: gzip or Brotli (usually 15–20% smaller than gzip for text).
  • The browser says what it accepts (accept-encoding: gzip, deflate, br, zstd); the server replies with content-encoding: br.
  • Compress text (HTML, CSS, JS, JSON, SVG). Don't re-compress JPEG, PNG, MP4 or WOFF2: they're already compressed.

Interview answer

Minification shrinks code itself by removing whitespace and comments and mangling local names, while compression encodes the bytes for transfer. Browsers advertise supported encodings in accept-encoding, and servers or CDNs respond with Brotli or gzip, indicated by content-encoding. Brotli typically beats gzip on text assets, and static assets can be pre-compressed at build time at maximum level. Already-compressed formats like images, video and woff2 fonts gain nothing from it.

The analogy

Packing clothes for a trip. Minify = fold them neatly and remove the hangers. Compress = vacuum-seal the bag. You don't vacuum-seal something that's already vacuum-sealed.

How it works

GET /assets/app.js
accept-encoding: gzip, deflate, br, zstd

200 OK
content-encoding: br
content-type: text/javascript

Common traps

  • Compressing images or fonts again wastes CPU for no gain.
  • Dynamic Brotli at max level is slow per request; pre-compress static files at build time instead.
  • Missing compression on JSON APIs. Large API responses benefit just as much as JS.

See it yourself

DevTools → Network → enable Big request rows: each row shows transferred size (compressed) above resource size (real). Check content-encoding in the response headers.

Quick quiz

Minification vs compression?

Minification changes the code to be smaller; compression encodes the bytes for transfer and is undone by the browser.

Which header tells you how a response was compressed?

content-encoding (e.g. br or gzip).

Should you Brotli-compress PNG files?

No. PNG, JPEG, MP4 and WOFF2 are already compressed.

  • Minify: strip whitespace/comments, rename locals. Compress: gzip, Brotli (≈ 15–20% smaller than gzip on text).
  • accept-encoding: gzip, deflate, br, zstd → content-encoding: br. See it: Network → big request rows show transferred vs real size.
  • Trap: don't compress JPEG/PNG/MP4/WOFF2 — already compressed. Compress text: HTML, CSS, JS, JSON, SVG.
