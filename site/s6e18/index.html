  • Revision episode: interview questions on collaboration.
  • Know how to build "typing…" for 200 people, how to stop lost updates on a profile form, the "cat" puzzle, and what to use for an offline notes app with no server.

Interview answer

For collaboration I send operations rather than whole documents, use ETags for optimistic concurrency on forms, keep ephemeral signals like typing throttled and out of the database, and use a CRDT library when edits must merge offline or without a central server.

Quick quiz

How do you implement a "typing…" indicator for a 200-person group?

Throttle typing events (~1 per 3 s), send them only to users currently viewing the chat, auto-expire the indicator on the receiver, and never store it in the database.

Two admins edit the same profile form and one loses changes. Fix?

Optimistic concurrency: include the ETag (version) with If-Match on save; on 412, reload and merge or ask the user.

"cat": one user inserts "h" at 1, another deletes at 2 concurrently. Result?

"cha". The delete is transformed to position 3 to account for the insert.

An offline-first notes app syncing between devices without a central server: what do you use?

A CRDT library such as Yjs or Automerge.

  • Typing for 200 (throttle ~3 s, viewers only, auto-expire, not in DB) · profile form lost updates (ETag + If-Match → 412 → merge) · "cat" puzzle ("cha": delete @2 → @3) · offline notes app with no server (CRDT library).
