Bubbling & capturing

Key points

  • A click travels in three phases: capture (down from window to the target), target, bubble (back up to window).
  • Listeners run in the bubble phase by default. Pass { capture: true } to run on the way down.
  • stopPropagation() stops the journey. preventDefault() stops the browser's default action (following a link, submitting a form). They're different things.

Interview answer

DOM events propagate in three phases: capturing from the window down to the target's parent, the target phase, then bubbling back up to the window. addEventListener listens in the bubble phase by default, or capture if you pass capture: true. event.target is the element that was actually clicked, while event.currentTarget is the element whose listener is running. stopPropagation stops further propagation; preventDefault cancels the default browser behaviour, and you can use either independently.

The analogy

A letter delivered to a flat. It goes down from the city post office to the building to the floor to your door (capture). You open it (target). Then the news spreads up: your floor hears, then the building, then the city (bubble). Anyone along the way can react, or stop the news from spreading further.

How it works

list.addEventListener('click', e => {
  console.log(e.target);         // the <button> you clicked (deepest element)
  console.log(e.currentTarget);  // the <ul> this listener is attached to
});

link.addEventListener('click', e => {
  e.preventDefault();      // don't navigate
  e.stopPropagation();     // and don't let parents hear about it
});

Common traps

  • target vs currentTarget. Mixing them up is the #1 bug in delegated handlers.
  • Not every event bubbles. focus, blur, mouseenter and mouseleave don't. Use focusin/focusout and mouseover/mouseout if you need bubbling.
  • stopPropagation breaks other code. Analytics, dropdown "click outside" handlers and delegation on parents stop working. Use it rarely.

See it yourself

DevTools → Elements → select an element → Event Listeners tab → tick Ancestors to see every listener that will hear a click on it.

Quick quiz

A div has a capture listener and its child button has a normal listener. Which runs first when you click the button?

The div's capture listener: capture runs on the way down, before the target and bubble phases.

Difference between stopPropagation and preventDefault?

stopPropagation stops the event from reaching other elements; preventDefault stops the browser's default action. A link click with preventDefault still bubbles.

Which common events don't bubble?

focus, blur, mouseenter, mouseleave (also load and scroll on elements).

  • Phases: capture ↓ → target → bubble ↑. Listeners default to bubble; { capture: true } for capture.
  • stopPropagation (stop the journey) ≠ preventDefault (stop default action).
  • target = clicked element, currentTarget = element whose listener runs. focus/blur/mouseenter/mouseleave don't bubble.
